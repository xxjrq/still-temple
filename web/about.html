静寺Still Temple

一间线上的山寺

不用注册，不用留名，进门坐一会儿就走。

首尔有一座山寺，把整座寺院做进了网页：你能在佛堂里看见别人也坐着，能听见远处的钟，能拨动一串念珠。静寺是这件事的中文版本，也是一个可以自己部署的开源项目。

没有账号体系，没有排行榜，也没有聊天框。你来的时候，系统随机给一个法名；走的时候，名字就消失。我们不保存你是谁。

在里面能做什么

  • 走进一间佛堂，坐下，看烛火和烟。
  • 拨动 108 颗念珠，可以记下自己拨了几轮。
  • 看见同一间屋子里还有别人在坐，不打扰彼此。
  • 换语言：中文、韩文、日文、英文、西班牙文、法文。

为什么开源

这个项目的前端来自韩国原站的公开产物，佛像与音效按各自许可使用，具体署名写在 NOTICE 里。后端是我们用 Go 重写的，只依赖标准库，一个二进制就能跑起来。

代码放在 GitHub，国内镜像在 Gitee。想自己搭一间，克隆下来按 README 走就行；想改成你自己的一间，改文案和贴图也够。

About (English)

Still Temple is a mountain temple you can enter from a browser. No sign-up, no name, no chat. You step in, sit for a while, and leave — the name you were given disappears with you.

The front end comes from the original Korean site's public build; the Go backend is written from scratch with the standard library only. Sources and credits are listed in NOTICE. Clone it and run your own.

Talk to us: t.me/stilltemple · GitHub Issues. We don't run ads and we don't sell anything.
